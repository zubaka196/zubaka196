# 🌐 FinNavigator Website

Сайт для оформления финансовых продуктов по модели агрегаторов вроде sravni.ru.

## Возможности
- Каталог банковских карт, кредитов, микрозаймов и финансовых предложений
- Карточка с изображением для каждого продукта
- Личный кабинет и административная панель
- Блок «Полезные сервисы»: курсы валют, калькуляторы, проверка КБМ
- Раздел работы и вакансий
- Партнёрские ссылки с маркировкой рекламы (erid)

## Стек
HTML / CSS / JavaScript. Дизайн: Creative, рынок: RU.
