# 🚗 Авто-проверка (в стиле «Номерограмм»)

Telegram-сервис проверки автомобилей с монетизацией.

## Возможности
- Проверка по VIN и госномеру
- Данные из открытых источников: Авито, Авто.ру, Дром и др.
- **ИИ-генератор объявлений** о продаже по марке, году, пробегу и цене
- Реферальная система: 1 друг = 1 проверка
- Админ без лимитов на проверки

## Стек
Python, aiogram 3, SQLite
