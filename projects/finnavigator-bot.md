# 🏦 Финансовый Навигатор — [@MoneyChoiceBot](https://t.me/MoneyChoiceBot)

Финансовый маркетплейс внутри Telegram с монетизацией через партнёрские предложения.

## Возможности
- Главное меню: Кредиты, Кредитные карты, Вклады, Инвестиции, Страхование, Реферальная программа, Поддержка
- Каталог: кредиты, рефинансирование, дебетовые и кредитные карты, вклады, инвестиции, страхование, SIM-карты, детские и пенсионные продукты
- Партнёрские ссылки и продукты импортируются из текстового файла
- Реферальная система с балансом пользователей
- Экспорт статистики в Excel
- Полноценный **Telegram Mini App**: поиск, фильтры, сравнение предложений
- Кнопки «Назад» во всех разделах, чистая консоль, поддержка с корректным именем пользователя

## Стек
Python 3.12+, aiogram 3 (polling), SQLite, python-dotenv, openpyxl, Docker / Docker Compose, Cloudflare (хостинг Mini App)

## Дорожная карта
Личный кабинет, админ-панель, микрозаймы, вакансии, полезные сервисы, версия для MAX.
