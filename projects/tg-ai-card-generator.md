# 🛍 ИИ-генератор карточек товаров

Telegram-бот и Mini App для создания карточек для Wildberries, Ozon и Avito.

## Возможности
- Загрузка фото товара, ИИ-фоны, блок преимуществ, превью карточки
- Удаление фона (Rembg), 3D-фоны (Flux / Midjourney)
- Оплата через **Telegram Stars (XTR)**: `send_invoice` и `pre_checkout_query`
- Админ-панель с бесплатной генерацией

## Стек
Python, aiogram 3, HTML + Tailwind CSS, Telegram WebApp SDK
